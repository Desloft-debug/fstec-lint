# fstec-lint 1.0.1 — предложенная версия

Исправительный выпуск ограничивает стоимость графов YAML aliases до построения объектов правил, улучшает обнаружение литералов в условных выражениях Compose и исключает значения инструкций Dockerfile из находок соответствующих правил.

Формат baseline остаётся v3. Fingerprints D002 и D005 изменились: проверьте отчёт и при необходимости создайте baseline заново. Старые HBA location с исходной строкой требуют явного пересоздания. Хеши слабых значений не обеспечивают секретность; защищайте отчёты и baseline.

Сканирование локальное и не исполняет инструкции конфигураций. PostgreSQL include и sshd Include не раскрываются. `--production-only` исключает только определённые имена вложенных каталогов, а не определяет назначение конфигурации. Лимиты ресурсов и границы чтения описаны в docs/security.md.

Перед публикацией проверьте уникальность версии и тега и дождитесь обязательных проверок CI и независимой приёмки.

## Кандидат 1.1.1.dev0

Это номер разработки, а не опубликованный релиз; проверка доступности номера через GitHub была недоступна. Разработка не прошла итоговую приёмку. Compose merge и PostgreSQL Include отсутствуют. Docker baseline следует пересоздать после просмотра находок; SSH Include использует локальную границу и не повторяет системную семантику OpenSSH целиком. DOCX формируется стандартной библиотекой. См. docs/verification.md и отчёты запуска.

## Исправления CI и baseline

Восстановлены настройки Temp и полный прогон матрицы Python. Mypy проверяет Windows API только для соответствующей платформы. Compose, Dockerfile и HBA проверяют путь открытого файла до чтения. Docker baseline использует устойчивые идентификаторы команд; старые текстовые Docker/HBA-записи допускают точное сопоставление с текущим исходником. Неоднозначные записи требуют пересоздания. Актуальные ограничения — в docs/security.md.
