# PostgreSQL Include

При разборе `postgresql.conf` поддерживаются `include 'file'`, `include_if_exists 'file'` и `include_dir 'directory'`. Относительный путь вычисляется от каталога файла с директивой. Подключённый файл читается на месте директивы: последнее значение параметра побеждает, а находка получает файл и строку победившего значения. Для `include_dir` читаются отсортированные файлы `*.conf`, кроме имён, начинающихся с точки. Отсутствующий `include_if_exists` пропускается; отсутствующие обязательный файл или каталог дают ошибку.

Чтение ограничено корнем сканирования; для явно указанного файла корень — его родительский каталог. Пути за границей, циклы и превышение бюджетов файлов, глубины или размера дают ошибку разбора. Имена Include должны быть заключены в одинарные кавычки. Подстановка окружения и полная грамматика PostgreSQL не реализованы. Проверка пути и последующее открытие не атомарны; не сканируйте дерево, одновременно изменяемое недоверенным субъектом. Ошибка разбора делает результат частичным; код CLI определяется описанным в README приоритетом находок и ошибок.

Эта поддержка относится к `postgresql.conf`. Директивы Include в `pg_hba.conf` не раскрываются и дают частичный результат. Продолжение HBA через обратную косую черту также отклоняется; закрытые двойными кавычками поля HBA разбираются с учётом кавычек и комментариев.
