# Архитектура

CLI (`fstec_lint/cli.py`) разбирает параметры, загружает правила для проверки `--select`/`--ignore`, вызывает движок и выбирает формат. `engine.py` загружает YAML из `rules/`, фильтрует правила, находит файлы, передаёт их соответствующим модулям `parsers/` и зарегистрированным функциям в `checks/`. Ошибка одного файла или проверки не останавливает обработку остальных. `reporters/` формирует text, JSON, HTML, SARIF и текстовый passport; `baseline.py` записывает и читает baseline v3.

`models.Rule` содержит ID, severity и метаданные правила; `models.Finding` связывает Rule с `file`, `location`, `detail` и необязательной `line`. `checks.base.CheckResult` — `(location, detail, line)` с необязательным четвёртым элементом `suppress_lines`. Движок собирает Finding и проверяет комментарии `fstec-lint: ignore`: они действуют на свою и следующую строку, а также на дополнительные строки подавления, возвращённые проверкой.

Fingerprint — `rule_id|relative_file|location`; `detail` и `line` в него не входят. Путь относителен текущему рабочему каталогу, когда это возможно без выхода выше него; иначе сохраняется исходный путь. Разделители зависят от платформы. Baseline v3 хранит ID, файл и location; D002/D005 не подавляются, поскольку их ordinal неоднозначен. HBA location использует хеш структурных полей и номер одинаковой записи без options; переход и ограничения описаны в [безопасности](security.md).

`ScanResult` содержит находки, ошибки и число подавленных находок. При обычном отчёте находка выше порога даёт код 1 с приоритетом над ошибкой частичного разбора (код 3); ошибки вызова дают код 2. `--write-baseline` возвращает 3 при неполном прогоне, иначе 0. Сканирование локальное; `--production-only` — фильтр имён, не классификатор. Контракты и известные ограничения описаны в [README](../README.md) и [безопасности](security.md).

Ошибки загрузки и проверки структуры YAML правил представлены `RulesError` (подкласс `ValueError`), без отражения значений; CLI сообщает их с кодом 2. При обходе цикл среди разрешённых каталогов прерывается и добавляется к ошибкам сканирования. Граф YAML проверяется до построения объектов и последующих преобразований; превышение бюджета приводит к контролируемой ошибке.

## Интеграционный кандидат

Движок проверяет границу вложенных чтений и связывает SourceLine с исходным файлом и suppression. При выборе файла граница — его родитель. PostgreSQL раскрывает три формы Include в порядке появления; применяются ограничения чтения и обхода `BoundedReader`. Проверка пути и открытие не атомарны: при подмене возможен выход за границу. Dotenv сообщает позиции комментариев, не выполняет подстановки окружения. Merge Compose не реализован, обнаруженная пара основного и override-файла, а также `include`/`extends` сообщают об ошибке. JSON CLI остаётся массивом находок. DOCX записывается бинарно, зависимости сверх стандартной библиотеки нет.
